# livox-sdk2-sys

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![MSRV](https://img.shields.io/badge/MSRV-1.77-red.svg)](https://blog.rust-lang.org/2024/03/21/Rust-1.77.0.html)

Raw, unmodified FFI bindings to the official
[Livox SDK2](https://github.com/Livox-SDK/Livox-SDK2) C API (62 functions),
generated by `bindgen` and compiled from source at build time.

> **You probably want [`livox-sdk2`](https://crates.io/crates/livox-sdk2)
> instead** — the safe, high-level wrapper built on top of this crate. Use
> `livox-sdk2-sys` only if you need direct access to the raw C API.

## How it builds

The official C++ SDK is **vendored** under `vendor/` (headers, `sdk_core`,
3rdparty — MIT licensed). `build.rs`:

1. compiles all C++ sources with the `cc` crate (C++11, pthread, no cmake
   required), and
2. generates `bindings.rs` from `livox_lidar_api.h` with `bindgen`.

The resulting static archive is linked into your binary — nothing is
installed on the system.

## Requirements

- Rust ≥ 1.77 (MSRV)
- A C++11 compiler (`g++` or `clang++`) and `libclang` at **build time**:
  ```bash
  sudo apt install -y g++ clang libclang-dev
  ```
- OS: Ubuntu 18.04+ (JetPack 5/6 included). Architectures: x86_64, aarch64.

## Usage

```rust
use livox_sdk2_sys::{GetLivoxLidarSdkVer, LivoxLidarSdkVer};

fn main() {
    let mut v = LivoxLidarSdkVer { major: 0, minor: 0, patch: 0 };
    // SAFETY: valid out-pointer.
    unsafe { GetLivoxLidarSdkVer(&mut v) };
    println!("{}.{}.{}", v.major, v.minor, v.patch);
}
```

## Safety

Every function here is the raw `extern "C"` API:

- you must follow the SDK lifecycle
  (`LivoxLidarSdkInit` → `LivoxLidarSdkStart` → … → `LivoxLidarSdkUninit`),
- several structs are `#[repr(C, packed)]` — never take references to their
  fields; use unaligned reads instead,
- callback and out-pointer arguments must stay valid for the SDK's use.
